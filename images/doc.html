Project 2 Process

For this API based website my goal was to create a way to search for pokemon based on their typing, name, or generation. The results are then displayed below the page for easy reference. The results show the pokemons official art and typing. The UI setup and layout consists of a search box to type in a specific pokemon by name. There are also 3 more drop downs to select pokemon typings and generation. The JavaScript worked by using event handlers for when the users hit the search button. When the search button is hit the filters the user applied in the website are then added to the search terms. On this page there are also previous and back buttons to cycle through pages of search results. These are implemented as the additional feature. To follow the rubric there is also a local storage component that takes a user previous search result, saves it to local storage for when the page is reloaded or reopened. Generative AI was used in this Project in order to either get context for confusing syntax elements by giving me examples of how to use them and also understanding how to use the pokemon API."
